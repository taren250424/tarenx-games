How to play

You are the warehouse keeper. Push every crate onto a goal spot (the dashed circles) to complete the level. Crates can only be pushed, never pulled — and you can push just one crate at a time. A crate shoved into a corner is stuck for good, so plan each push before you make it. Finished crates turn green.

Controls

  • ↑ ↓ ← → or WASD — move
  • Z or U — undo (unlimited)
  • R — restart level
  • On touch screens: swipe the board or use the on-screen arrows

Strategy tips

  • Watch the corners. A crate pushed into a corner (or against a wall with no goal along it) can never be recovered. Learn to spot these dead squares before pushing.
  • Order matters. Many levels have only one working order for the crates. If a crate blocks the path you need for another, solve the far crate first.
  • Think in pushes, not steps. Walking is free — what counts is where you stand before each push. Ask "can I get behind the crate?" rather than "can I reach the crate?".
  • Use undo freely. Experimenting is part of the game. Undo is unlimited, so try a line of pushes and roll back if it dead-ends.

About Sokoban

Sokoban (倉庫番, "warehouse keeper") was created in Japan in the early 1980s and has become one of the most studied puzzle games ever — solving arbitrary Sokoban levels is PSPACE-complete, which is why even tiny boards can be surprisingly deep.

Two collections are included. The Starter Set (18 levels) was created for Tarenx Games and arranged from a gentle first push to multi-crate warehouses. Microban (155 levels) is the beloved beginner-friendly collection by David W. Skinner, included here with attribution as the author intended — thank you, David. Level transcriptions are machine-verified with a Sokoban solver.
